# 第一阶段使用可配置的本地 AI 执行顺序

localhost 阶段通过隔离、只读、临时且结构化的本地 CLI 任务执行 AI 属性判断。默认执行顺序为 Claude Code CLI、Codex CLI，以保留用户主要用于编程工作的 Codex 使用额度；本地用户可以在设置页启用、停用和调整顺序。两个 CLI 都自行管理各自登录，应用不读取或复制任何登录凭证。Platform API Key 只在用户明确配置并启用后才参与执行。

只有额度、限流、登录失效、超时或服务不可用会自动尝试下一个执行器；结构化输出错误由原执行器重试一次，业务输入错误不触发降级。所有已启用执行器均不可用时记录失败并把相关商品转为 AI 待处理。
